This project includes original local experiments and adaptations of public Kaggle work. The goal of this file is to make provenance explicit before any public release.

## What Is Not Included

This repository intentionally excludes:

- Kaggle competition data;
- generated CSV submissions;
- model weights;
- Kaggle notebook output directories;
- private datasets;
- credentials;
- raw agent chat logs.

## Public Release Note

Before making this repository public, review the source licenses and Kaggle sharing rules for any copied notebook code. If in doubt, publish links and provenance notes rather than redistributing full public notebooks.
